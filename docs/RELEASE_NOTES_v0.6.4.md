# rest-sample-cache-reader 0.6.4

This patch aligns the runnable reader with `rust-java-rest:4.5.0` and
`java-rust-cache:0.7.4`. Both dependencies package the same clean Windows and Linux native runtime
with REST ABI `29`, Dubbo ABI `7`, Redis ABI `6`, and Glowroot ABI `3`.

Routes, Redis keys, projection contracts, and Java business code are unchanged.
