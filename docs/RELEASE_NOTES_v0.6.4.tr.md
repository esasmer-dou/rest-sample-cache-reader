# rest-sample-cache-reader 0.6.4

Bu patch, çalışan reader uygulamasını `rust-java-rest:4.5.0` ve `java-rust-cache:0.7.4` ile
hizalar. İki bağımlılık da REST ABI `29`, Dubbo ABI `7`, Redis ABI `6` ve Glowroot ABI `3` taşıyan
aynı temiz Windows ve Linux native runtime'ını paketler.

Route'lar, Redis key'leri, projection kontratları ve Java iş kodu değişmedi.
