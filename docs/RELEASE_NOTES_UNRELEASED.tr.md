# Henüz Yayımlanmamış Belge Düzeltmeleri

[English](RELEASE_NOTES_UNRELEASED.md) | [Türkçe](RELEASE_NOTES_UNRELEASED.tr.md)

Sample `0.8.0`, cache `0.9.0`, REST/platform `4.8.0` ve isteğe bağlı agent `0.7.1`
için yalnız belge düzeltmesidir; yeni özellik sürümü değildir.

- Yayımlanmış L1/tazelik özelliklerinin yayımlanmamış kardeş derleme gerektirdiği iddiası kaldırıldı.
- Gerçek `CacheReadValue` HTTP yolu açık snapshot sahipliğinden ayrıldı; L1 belleği isteğe bağlı ve replica başına kaldı.
- Profil/çalıştırma rehberleri eşleştirildi; eski not-ready `404` ile isteğe bağlı ortak hata/tazelik `503` ayrıldı.
- Türkçe bağlantılar ve kullanıcı rehberindeki bulunmayan jlink akışı düzeltildi. PDF'ler önceki kopya olarak kaldı.

Runtime varsayılanları ve geçmiş sürüm/test beyanları değişmez. Yeni performans
doğrulaması iddia edilmez.
